# Brazilian Legislative Data Pipeline

A comprehensive Data Engineering pipeline demonstrating advanced Databricks capabilities using the Brazilian Chamber of Deputies API.

* **Architecture:** Medallion Architecture (Bronze, Silver, Gold) with Unity Catalog governance.
* **Storage & Processing:** Delta Lake and PySpark for scalable data transformations.
* **Advanced Features:** CDC (Change Data Capture) with SCD Type 2 for tracking bill status history, and anomaly detection modeling.
